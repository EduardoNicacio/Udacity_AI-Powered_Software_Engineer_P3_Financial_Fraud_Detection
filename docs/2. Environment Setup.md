# Environment Setup

## Project Environment

There is limited environment set up required for this project, as it is primarily geared around testing your analytical abilities rather than developing software.

You can complete this project in a word processor (such as Microsoft Word, Google Docs, LaTeX) or IDE of your choosing. You may be inclined one way or another based on the diagramming tool that you choose to use. Your final deliverable must be submitted as a PDF, irrespective of how you develop the report itself.

## Local Machine Instructions

You may want to use one of two options for diagramming that requires local setup. This setup assumes you are using Visual Studio Code. If you are using another IDE, you may need to source your own setup instructions.

### Mermaid

Install this [plugin](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid). Once enabled you can use Mermaid syntax inside of code blocks in Markdown and the plugin will render them in any previews you might be as SVG.

### D2

[Install D2](https://d2lang.com/tour/install), then install this [plugin](https://marketplace.visualstudio.com/items?itemName=terrastruct.d2). Once enabled you can use D2 syntax inside of code blocks in Markdown and the plugin will render them in any previews as SVG.

### draw.io

[draw.io](https://www.drawio.com/) is a free web-based diagramming tool. It's highly flexible and integrates with multiple storage options to make keeping it alongside other documentation easy.
